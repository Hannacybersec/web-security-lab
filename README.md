# Web Security Testing Lab

A practical web security assessment lab built with **Kali Linux, Python SimpleHTTPServer, cURL, and Nikto**.

The project demonstrates basic web security testing techniques against a **locally hosted, authorized test website**.

## 🎯 Objectives

- Inspect HTTP responses and headers
- Identify exposed server information
- Check common security headers
- Test supported HTTP methods
- Observe web-form input handling
- Check for directory-listing indicators
- Perform automated web security scanning with Nikto
- Document security findings and observations

## 🛠️ Technologies & Tools

- Kali Linux
- Python
- HTML
- cURL
- Nikto
- HTTP/1.x
- Git & GitHub
